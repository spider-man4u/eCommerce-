## 🌟 Features

### Core Functionality
- ✅ **User Authentication** (JWT + Social Logins)
- 🛒 **Smart Cart System** with local storage persistence
- 💳 **Stripe/PayPal Integration** with test mode
- 🔍 **Algolia-Powered Search** with instant results

### UI/UX Highlights
- 🎥 **Product Video Previews**
- ✨ **Framer Motion Animations**
- 🌓 **Dark/Light Mode Toggle**
- 📱 **Mobile-First Responsive Design**

### Admin Capabilities
- 📊 **Analytics Dashboard**
- 📦 **Inventory Management** (CRUD Operations)
- 📨 **Bulk Email Campaigns**
- 🛡️ **Role-Based Access Control**

## 🚀 Quick Start

### Prerequisites
- Node.js ≥18.x
- MongoDB Atlas cluster
- Stripe account

### Installation
```bash
# Clone repository
git clone https://github.com/yourusername/ecommerce-platform.git

# Install dependencies
cd ecommerce-platform
npm run setup-deps # Installs both backend + frontend dependencies

# Configure environment variables
cp .env.example .env
